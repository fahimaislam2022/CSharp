# BuyNix - Super Shop Management System

A comprehensive **Shop Management System** built with C# and MS SQL Server, designed to manage shopping operations including products (food, gadgets, and fashion), user and seller accounts, and transaction management.

## 📋 Overview

BuyNix is a desktop application that provides a complete solution for managing a super shop with multiple product categories. It features separate login portals for admins, sellers, and customers, along with inventory management and sales tracking capabilities.

## 🛠️ Technology Stack

- **Backend**: C# (.NET Framework)
- **Database**: MS SQL Server
- **UI Framework**: Windows Forms (WinForms)
- **Language Composition**: 99.8% C#, 0.2% T-SQL

## ✨ Features

### User Management
- **Admin Portal**: Administrative control and user management
- **Seller Account**: Seller registration and login
- **Customer Account**: User registration and login
- **Role-based Access Control**: Different permissions for admins, sellers, and customers

### Product Categories
- **Foods**: Browse and manage food products
- **Gadgets**: Electronics and gadgets catalog
- **Fashion**: Clothing and fashion items

### Core Functionality
- Product browsing and information display
- Shopping cart and purchase management
- Seller inventory management
- Admin dashboard for user and product management
- Purchase history and transaction tracking

### User Interface
- Login and registration screens for multiple user types
- Product catalog views with detailed information
- Shopping phases and checkout process
- Admin panel for system management
- Seller dashboard for inventory management
