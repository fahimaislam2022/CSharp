## 📌 Overview

**BuyNix** is a desktop application designed to manage supermarket operations efficiently. It provides role-based access for **Admins**, **Sellers**, and **Customers**, allowing users to manage inventory, browse products, and maintain records through a simple graphical interface.

This project demonstrates practical implementation of:

- Windows Forms application development
- SQL Server database integration
- User authentication and registration
- Product management with CRUD operations
- Role-based navigation and access

---

## ✨ Features

### 🔐 Authentication System
- User registration
- User login
- Seller login
- Admin access
- Duplicate username checking
- Password confirmation validation

### 📦 Inventory Management
- Add products
- Update products
- Delete products
- Search products by ID
- View products in `DataGridView`

### 🛍️ Product Categories
- Foods
- Gadgets
- Fashion

### 👥 Role-Based Access
- **Admin**: Manage system and products
- **Seller**: Add and manage items
- **Customer**: Browse and view products

### 🗄️ Database Support
- SQL Server integration
- ADO.NET connectivity
- Parameterized SQL queries
- Structured product and user data management
